# Security Policy

## Supported versions

Security fixes are applied to the latest release on `main` (currently 0.2.x).

## Reporting a vulnerability

Please report security issues privately via
[GitHub Security Advisories](https://github.com/phzwart/leanmap/security/advisories/new)
for this repository. Do not open a public issue for vulnerabilities.

Include a short description, impact, and steps to reproduce if possible. We will
acknowledge receipt and work on a fix or mitigation.
